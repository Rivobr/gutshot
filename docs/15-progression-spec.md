## 2. Уровни 1–100

Первый переход стоит **250 XP**, далее шаг дорожает:

| Диапазон | Шаг дорожает на |
| -------- | --------------- |
| 1 → 10   | +60 XP          |
| 10 → 25  | +80 XP          |
| 25 → 50  | +100 XP         |
| 50 → 75  | +120 XP         |
| 75 → 100 | +140 XP         |

Контрольные значения (накопительный XP):

| Уровень |      XP | Уровень |          XP |
| ------: | ------: | ------: | ----------: |
|      10 |   4 410 |      70 |     217 010 |
|      20 |  15 910 |      75 |     252 660 |
|      30 |  35 610 |      80 |     291 510 |
|      40 |  65 010 |      90 |     379 710 |
|      50 | 104 410 |     100 | **481 910** |
|      60 | 154 710 |         |             |

- XP сверх стоимости уровня переносится дальше: за одно начисление можно
  подняться на несколько уровней подряд.
- После 100 уровня уровень не растёт, XP продолжает копиться
  в статистике и рейтинге.

Проверяется тестом `apps/api/src/common/constants/xp.constants.spec.ts`.

## 4. Достижения

Каталог: `apps/api/src/common/constants/achievements-catalog.ts`.
Отдаётся клиенту через `GET /api/v1/achievements/catalog`.

Группы:

| Группа                          | Ступени                                                                                        |
| ------------------------------- | ---------------------------------------------------------------------------------------------- |
| 🏆 Победы                       | 1 / 3 / 5 / 10 / 15 / 25 / 50                                                                  |
| 🎯 Финальные столы              | 1 / 5 / 10 / 25 / 50 / 100 / 250                                                               |
| 🎮 Сыгранные турниры            | 5 … 1000                                                                                       |
| 🔥 Активные недели (3+ турнира) | 5 / 10 / 25 / 52 / 100                                                                         |
| 📈 Недельный рейтинг            | топ-3 ×1/3/10/25, победы ×1/5/10/25                                                            |
| 👑 Финал месяца                 | участие, приз, победы ×1/3/5/10                                                                |
| 🃏 Каре                         | 1 / 5 / 10 / 30 / 50 / 100                                                                     |
| 🎴 Стрит-флеш                   | 1 / 3 / 5 / 10                                                                                 |
| 💎 Роял-флеш                    | 1 / 2 / 5                                                                                      |
| ⚡ Особые                       | без ре-энтри, 2 победы подряд, 3 финалки подряд, 5× топ-10 подряд, стек <10 BB, обучение, друг |
| 💀 Нокауты                      | 1 … 1000                                                                                       |
| 👑 Легенда Gutshot              | сводный чеклист, 50 000 XP                                                                     |

XP за достижение начисляется **один раз** — таблица `PlayerAchievement`
(уникальный индекс `userId + achievementId`).

Пересчёт запускается после: завершения турнира, события сканера,
выплаты наград рейтинга.

### Легенда Gutshot

Требования: 50 уровень, 100 турниров, 10 побед, 25 финальных столов,
3 попадания в топ-3 недели, призовое место в финале месяца,
5 каре или 1 стрит-флеш, победа без ре-энтри. Награда — 50 000 XP.

---

## 5. Особые события (отмечает администратор)

В сканере добавлены кнопки:

- **Победа с &lt;10 BB** → `SHORT_STACK_WIN`
- **Обучение** → `TUTORIAL_COMPLETED`
- **Привёл друга** → `FRIEND_REFERRED`

Сами события XP не дают — награду выдаёт достижение при первом выполнении.
