# Offline TV APK — утверждённый дизайн (2026-08-06)

Статус: **утверждено**.

## Экраны

1. **Планирование** — выбор времени старта MSK, шаблон клуба, кнопка «Запланировать» на каждом TV.
2. **Ожидание старта** — время старта + обратный отсчёт до MSK.
3. **Игра** — логотип, Малый/Большой, Ante (капсула), Далее, Уровень / До смены / До перерыва.
4. **Перерыв** — крупный таймер по центру; внизу только Уровень и Блайнды (следующие).
5. **Финиш** — «Турнир завершён» → «В меню».

## Убрано

- название турнира («Открытие клуба»)
- «Играют»
- LIVE / статус-pill

## Визуал

- фон: тёмный градиент `#120e09 → #090907` (как текущий web-TV)
- логотип: `gutshot-logo.png` из бота/mini-app
- типографика: system-ui labels + Georgia numbers
- золото `#c89a3d` / крем `#fff8e6`

## Логика

- офлайн, без интернета
- старт синхронизируется по wall-clock **Europe/Moscow**
- встроенный шаблон клуба: ante = BB, перерывы **7 / 7 / 12** мин
- после финиша — возврат в меню планирования
- целевые экраны: 33″ и 55″, 16:9
