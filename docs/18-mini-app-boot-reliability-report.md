# Отчёт по входу в бота / Mini App

**Дата обновления:** 2026-08-07  
**Прод:** `app.gutshotapp.ru` · бот `@gutshotpokerbot` · VPS `/opt/gutshot`  
**Сейчас на сервере:** см. деплой · entry `enter.html?v=20260807d` · boot через `GET /profile/bootstrap`

---

## 1. Как должен выглядеть нормальный вход

```text
/start в боте
  → кнопка «Открыть GUTSHOT»
  → enter.html (Входим…)
  → логин (initData или ticket)
  → «Открываем клуб…» → переход в приложение
  → если нет согласия → экран «Согласен»
  → Home (клуб)
```

**Канонический URL:** `https://app.gutshotapp.ru/enter.html?v=20260807c`

## 2. Симптом → причина → что делать игроку / нам

| Что видит человек                                 | Вероятная причина                                                  | Решение для игрока                                                                                     | Решение для нас (постоянное)                                                     |
| ------------------------------------------------- | ------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------- |
| Вечная крутилка **«Открываем клуб…»** (5 полосок) | iOS/Telegram WebView **не делает** `location.replace` после логина | Закрыть → `/start` → новая кнопка. Если снова крутится — нажать **«Открыть клуб»** (появляется ~1 сек) | Уже на проде: multi-nav + кнопка. Дальше: не зависеть от programmatic navigation |
| Крутилка **«Открываем клуб…»** с PNG-логотипом    | React `useStartup` / повторный логин                               | Подождать до 10–15 сек или переоткрыть                                                                 | Уже: если JWT есть с enter — сразу `ready`                                       |
| **«Загружаем профиль…»** долго                    | Тяжёлый `GET /profile` (метрики, ачивки)                           | «Повторить» / переоткрыть                                                                              | Сделать лёгкий `/me/bootstrap` для входа                                         |
| Экран **«Согласен»**, «не пускает в клуб»         | Нет `consentAcceptedAt` — это **не баг**, так задумано             | Нажать «Согласен»                                                                                      | Для VIP/теста можно проставить в БД (как для @Sheegol)                           |
| **«Ссылка устарела»** / ticket 401                | Старая кнопка из старого сообщения                                 | Только `/start` и **новая** кнопка                                                                     | Ticket TTL 7 дней; menu button без ticket ок                                     |
| **«Откройте кнопкой из бота»**                    | Нет `initData` (открыли не из Telegram / битый WebView)            | Открывать только кнопкой бота/меню                                                                     | Ticket в `/start` как запасной путь                                              |
| Бот **молчит** на `/start`                        | Webhook/API                                                        | Написать админу                                                                                        | API при старте сам ставит webhook + menu                                         |
| Синий/странный placeholder Telegram               | WebView ещё не отрисовал / завис                                   | Закрыть полностью и открыть снова                                                                      | Убрать опасные API с boot (fullscreen уже убран)                                 |
| Открыли старую ссылку `/t.html`                   | Кэш старого entry                                                  | `/start` → новая кнопка                                                                                | Menu всегда на `enter.html?v=`                                                   |

## 5. Оставшиеся риски (ещё могут быть у людей)

1. **Тяжёлый `/profile` на входе** — главный технический долг после UI-фикса.
2. **Нет телеметрии по этапам входа** — узнаём о проблемах от игроков, а не из алертов.
3. **Старые сообщения бота** с протухшим ticket — лечится только новым `/start`.
4. **Слабый интернет в клубе** — WebView Telegram чувствителен; нужны короткие таймауты + кнопка повтора (частично есть).
5. Если снова добавить fullscreen/тяжёлые вызовы на boot — регресс.

## 6. Инструкция поддержки (коротко)

**Игрок пишет «не заходит»:**

1. Спросить скрин / текст на экране.
2. Сказать: закрыть Mini App → `/start` → новая кнопка.
3. Если «Открываем клуб…» — ждать кнопку **«Открыть клуб»** и нажать.
4. Если экран **«Согласен»** — нажать.
5. Если ticket устарел — только новый `/start`.
6. Если снова нет — проверить в БД:
   - есть ли `User` по `username`
   - есть ли `consentAcceptedAt`
   - смотреть свежие `ERROR` в `docker logs gutshot-api`

**Проставить согласие вручную (если надо):**

```sql
UPDATE "User"
SET "consentAcceptedAt" = NOW(), "updatedAt" = NOW()
WHERE username = 'Sheegol';
```

## 7. План, чтобы больше не вспоминать

| Приоритет | Задача                                                        | Зачем                                |
| --------- | ------------------------------------------------------------- | ------------------------------------ |
| P1        | Лёгкий `GET /me/bootstrap` вместо полного `/profile` на входе | Вход не зависит от метрик/ачивок     |
| P1        | CI-запрет `requestFullscreen` в boot-файлах                   | Не вернуть регресс                   |
| P1        | Авто `v=<git sha>` в menu/`/start`                            | Не кэшировать старый enter           |
| P2        | Телеметрия этапов входа + алерт в Telegram                    | Видеть fail rate раньше игроков      |
| P2        | Post-deploy smoke: enter + health + menu URL                  | Деплой без «авось»                   |
| P3        | Урезать first JS bundle                                       | Быстрее first paint в слабом WebView |

## 8. Итог одной фразой

**Большинство «не заходит» сейчас — это WebView Telegram (крутилка после логина), старая кнопка, или ненажатое «Согласен». Сервер и auth в порядке.**  
На проде уже есть обход (кнопка «Открыть клуб» + fast-path). Чтобы закрыть тему системно — лёгкий bootstrap API и мониторинг входа.
