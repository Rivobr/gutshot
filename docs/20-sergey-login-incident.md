# Инцидент: бесконечная загрузка Mini App (DNS через Cloudflare-прокси)

Дата: 2026-08-07

## Симптом

- Пользователи заходят в Telegram и в бота (кнопка приходит), но при открытии
  Mini App — **бесконечная загрузка**. Часть сидит через VPN.

## Причина (root cause)

DNS-записи `app`/`api`/`admin` в Cloudflare были **оранжевые (proxied)**.
Поэтому `app.gutshotapp.ru` резолвился в **прокси-IP Cloudflare**
(`104.21.x` / `172.67.x`), а не в сервер.

Российские провайдеры режут/блокируют IP Cloudflare → TLS/запросы к Mini App
до edge Cloudflare не доходят или висят → **бесконечная загрузка**.
Сам бот работает, потому что `/start` и доставка кнопки идут через инфраструктуру
Telegram, а не через устройство пользователя.

Дополнительно всё усугублял «split-brain»: домен готовили к переезду на Beget,
записи то оранжевые, то серые — разные резолверы отдавали разные адреса.

## Что исправлено (сервер/DNS)

1. Все A-записи в Cloudflare → **серые (DNS-only)**, напрямую на
   `159.194.208.116` (это IP Beget, РФ — доступен из России без VPN и с VPN).
   Проверено: авторитетные NS Cloudflare (`shubhi`/`alec`), `1.1.1.1`, `8.8.8.8`,
   Яндекс `77.88.8.8` — все отдают `159.194.208.116`. TTL 60с — кэш чистится за минуту.
2. Origin-сертификат (Let's Encrypt) покрывает `app`/`api`/`admin`/`tv` — HTTPS
   валиден при прямом заходе.
3. Webhook Telegram → `https://app.gutshotapp.ru/api/v1/telegram/webhook`,
   `ip_address=159.194.208.116`, ошибок нет.
4. Кэш входа поднят до `v=20260807f`, задеплоено.
5. Безопасность: удалены malware-ключи из открытого наружу Redis; порты
   Redis/Postgres/API закрыты на `127.0.0.1`; убран host-сервис `cloudflared`
   (мёртвый туннель); из аватарок убран bot-token (светился в URL).

## ВАЖНО про переезд на Beget

На данный момент **Beget НЕ хостит DNS-зону** домена: его NS (`ns1.beget.com` и
др.) на запрос отвечают SOA `alec.ns.cloudflare.com`, т.е. просто пересылают в
Cloudflare. Регистратор `.ru` тоже всё ещё на NS Cloudflare.

Если сейчас переключить NS на Beget без заранее созданной зоны — домен **погаснет
полностью (NXDOMAIN)**, и в бота не зайдёт никто.

### Рекомендация

- **Оставить NS на Cloudflare с серыми записями** — всё уже работает и доступно в
  РФ. Причина ухода (оранжевый прокси Cloudflare резался в РФ) устранена именно
  переводом в серые записи. Уходить с NS Cloudflare не обязательно.
- Если всё же переезжать на Beget: сначала создать в панели Beget DNS-зону с
  A-записями `@/app/api/admin/tv → 159.194.208.116` (**без CDN Beget**), убедиться
  `dig @ns1.beget.com app.gutshotapp.ru` → `159.194.208.116`, и только потом
  менять NS у регистратора. CDN Beget для `app`/`api` не включать — сломает вход.

## Что сделать пользователям сейчас

Полностью закрыть Telegram (смахнуть из недавних, не просто «назад»), подождать
~1 минуту (кэш DNS), снова открыть бота и нажать свежую кнопку «Открыть клуб».
Старый IP Cloudflare был закэширован на устройстве; при TTL 60с чистится за минуту.

## Остаточные задачи по безопасности (не блокируют вход)

- Перевыпустить токен бота в BotFather (светился в URL аватарок) и обновить `.env`.
- Сменить пароль админки `owner@gutshot.club` (пока seed `ChangeMe123!`).
- Ротировать Cloudflare API-токен после стабилизации DNS.
